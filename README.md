# Defendypoo
The arcade game featuring Bandit the Dog, a black and tan border collie. Bandit is the leader of the resistance and needs your help to fight against an alien attack.  Can you pilot a craft and save the humanoids? 

Use your tools to defeat the enemy and reach new locations. Be like a good dog, loyal and brave and help save the day. 

Save the humanoids.
